# learnanylanguage 0.2.0

Four new tracks, three new languages, and experimental lesson types for
grammar, vocabulary and writing, in voice or typed. Teacher prompt **g3**.

## Languages and tracks

- Language profiles: **Swedish** (`sv`), **Polish** (`pl`), **Japanese**
  (`ja`), with a new `text_rule` key for typed lessons in every profile.
- `sv-everyday`: everyday Swedish (du), 3 sessions.
- `pl-first-steps`: a first stay in Poland (pan/pani), 3 sessions.
- `ja-first-steps`: polite everyday Japanese (です／ます), 3 sessions; romaji
  only in the material, never in packages.
- `uk-advanced`: opinions, storytelling with aspect, news and society
  (-но/-то forms), 3 sessions; openings stress-checked with `lal audit`.
- Each new session has Grammar, Vocabulary and Writing sections.

## Lesson types (experimental, prompt g3)

- `grammar` (voice or text): one pattern, 6–10 cue → answer items, a repeat
  pass.
- `vocabulary` (voice or text): 6–10 words found from prompts and used in a
  sentence, a repeat pass.
- `writing` (text): a short text, a minimal rewrite with at most five
  reasoned corrections, one follow-up.
- Typed lessons: `--channel text` builds a TEXT_SESSION_PACKAGE for an
  ordinary ChatGPT chat.
- Optional report: after the close the learner types `REPORT` and the
  teacher writes a factual LESSON_REPORT; `lal report` checks it, and the
  record workflow verifies it against the transcript.

The repetition, guided and free modes render exactly as in g2 apart from the
version line. Adherence checks C19–C23 cover the new modes.
