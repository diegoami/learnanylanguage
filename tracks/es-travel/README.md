# Spanish for a first trip (es-travel)

Three short sessions for a beginner going to Spain: greetings and getting by,
café and paying, directions and transport. Formal register (**usted**).
All dialogues are original.

- [MATERIAL.md](MATERIAL.md): dialogues with translations, patterns, and
  checklists to study before each lesson.
- [PLAN.md](PLAN.md): lesson parts and when a session counts as covered.
- [OPENINGS.md](OPENINGS.md): teacher introductions and listen-and-repeat
  lines (copied into packages by `lal`).
- [TRACKER.md](TRACKER.md): the empty tracker that `lal start` copies.

In voice mode, start the lesson with **«Empecemos»**; it ends with «La clase
ha terminado.». Spanish spelling already shows irregular stress, so the
lines carry no extra marks; `lal audit` checks ¿…? and ¡…! pairs and
accented question words instead.
