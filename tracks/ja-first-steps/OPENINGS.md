# Voice opening scripts

`lal lesson new` copies these scripts into lesson packages. A **repetition**
lesson uses the opening review lines as its Lines; a **guided conversation**
uses the teacher introduction before its first step. Other modes use neither.
Keep the format — a `## Teacher introduction` blockquote and an
`## Opening review` bullet list — because the tool parses it. Japanese script
only: no romaji here.

---

# Session 1 — Introductions

## Teacher introduction

> 今日は自己紹介の練習をしましょう。どこから来たか、どこに住んでいるか、仕事は何かを話します。

## Opening review

- はじめまして。
- お名前は何ですか。
- どちらから来ましたか。
- イタリアから来ました。
- 今はドイツに住んでいます。
- お仕事は何ですか。
- エンジニアです。
- 日本語を少し話します。
- すみません、もう一度お願いします。
- ゆっくり話してください。
- よろしくお願いします。

# Session 2 — Shopping and ordering

## Teacher introduction

> 今日はお店とカフェで注文する練習をしましょう。ほしい物を言って、値段を聞いて、払います。

## Opening review

- いらっしゃいませ。
- コーヒーを一つください。
- これは何ですか。
- それは抹茶ラテです。
- じゃあ、それを二つください。
- いくらですか。
- 千二百円です。
- カードで払えますか。
- はい、大丈夫です。
- 袋はいりません。

# Session 3 — Time and plans

## Teacher introduction

> 今日は時間と予定について話しましょう。毎日の生活と、週末に何をするかを話します。

## Opening review

- 今、何時ですか。
- 三時半です。
- 毎朝七時に起きます。
- 週末は何をしますか。
- 土曜日に京都へ行きます。
- 日曜日はうちで休みます。
- 一緒に映画を見ませんか。
- いいですね。行きましょう。
- すみません、日曜日はちょっと…。
- 昨日は友達と晩ご飯を食べました。
